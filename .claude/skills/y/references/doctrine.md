## 1. 根本原理

役割論理とは、ダメージレース（互いの HP を削り合う攻防）と相手への負担集中を重視し、圧倒的な火力でサイクル戦を崩壊させることで勝利を獲得する戦術思想である。

### 1.1 価値観の序列

努力値／SP 配分の優先順位は次のとおり一貫している。

```
A or C（メイン火力）
  > H・B・D（耐久三種）
  ≧ サブ火力（両刀の場合のみ）
  > S
  >>> 使用しない火力ステータス
```

要約すれば「**火力 > 耐久 >>> 素早さ**」。火力と耐久は近接した優先度を持つが、両者が競合した場合は火力が常に優先される。

### 1.2 中核概念

| 概念 | 定義 |
|------|------|
| 役割 | タイプ相性や耐久で有利な対面に繰り出し、受け出しから相手を倒しきること。交代戦のなかで各ポケモンが担う「果たすべき仕事」。 |
| 役割遂行 | 受け出し（交代で受ける）→ 想定される役割破壊技を耐える → 返しの攻撃で撃破、という一連の手順を完遂すること。 |
| 役割破壊 | 受けに来た相手に対して、想定外の技で大ダメージを与え、役割関係を壊す行為。 |
| サイクル | ポケモンを交代しながら役割を回し続ける試合展開。 |
| サイクル崩壊 | サイクルを維持できなくなった状態。ここまで追い込まれると敗北が濃厚。 |
| ダメージレース | 双方の残 HP 削り合い。役割論理の勝利条件はこれに勝つこと。 |
| 打ち合い | 交代を介さず技を撃ち合う局面。サイクル崩壊後の終盤で必然的に発生する。 |

### 1.3 ヤケモン（役割を持てるポケモン）の条件

ヤケモンとして採用可能な個体は、以下の条件を**すべて**満たす必要がある。

1. 火力（A または C の種族値と技威力）
2. 範囲（攻撃技のタイプバリエーション）
3. 耐性（タイプ相性）
4. 耐久（HBD の種族値）
5. 受け出し可能な耐久水準（サイクル戦に耐える）
6. ダメージレースを制する火力水準
7. 上位互換となるヤケモンが存在しないこと

「対面で耐えて下から殴れる」だけでは不十分で、受け出しから遂行まで通せるかが要点となる。下位互換が明白なポケモンの採用は原則禁止。

## 2. 禁則事項（Hard Rules）

以下に1件でも違反するものは「論外」と判定され、ヤトリック／ヤロテスタントいずれからも容認されない。

### 2.1 性格

許容される性格は以下の 4 種のみ。

- いじっぱり（A↑ / C↓）
- ひかえめ（C↑ / A↓）
- ゆうかん（A↑ / S↓）
- れいせい（C↑ / S↓）

採用根拠:

- 物理／特殊どちらかの火力を上げることが必須要件。
- 耐久を下げる性格（ようき・おくびょう等）は受け出し性能を削ぎ、サイクル崩壊を早めるため不可。
- ゆうかん／れいせいは、両刀型または S を下げるメリット（ジャイロボール運用等）がある場合に限定的に使用される。

### 2.2 努力値 / SP 配分

| 部位 | ルール |
|------|------|
| A または C | 極振り必須（従来 EV=252 / Champions SP=32） |
| H / B / D | 残余をすべて耐久に投入。最硬振りまたは HBD 均衡振り |
| S | 基本的に振らない。従来仕様での「言い訳振り」+4 のみ許容 |

**言い訳振り**: HBD に配分した残りの 4 EV を S に回す従来仕様での配分法。Champions SP は合計 66 をぴったり使い切れるため、このパターンは発生しない。

**S 振り禁止の論拠**:

- 交代は素早さに依存しないため、受け出しを基本戦術とする限り S は不要。
- 有利対面が維持できれば、相手が居座っても役割遂行は成立する。
- 環境因子による S 調整は過去の第五世代ポイヒガッサ対策の例のみ歴史的例外として許容。

### 2.3 技構成

採用可能な技は攻撃技（物理／特殊）のみ。以下の制約をすべて満たすこと。

1. **補助技（変化技）の採用禁止**
   技スペースの無駄であり、無効化手段が多く、交代で効果が消失し、無償降臨を許す等の理由による。
2. **状態異常技の採用禁止**
3. **先制技（priority > 0）の採用禁止**
   - 例外: そのポケモンが覚える「特定タイプの最大打点」が先制技である場合のみ容認（例: であいがしらを最大打点として採用するケース）。
   - ただし「ふいうち」は**無償降臨を許す**ため、最大打点であっても絶対に採用不可。
4. **タイプ一致攻撃技を最低 1 つ含む**
   - 例外: 複合タイプで一致技が 1 種しか覚えられないポケモン（一致技 1 本のみの構成となる）。
5. **連続技／音技／ねごとはヤトリックでは不採用**
   ヤロテスタントでは環境因子として一部容認。
6. **命中を理由に威力を下げる選択は不可**
   論者は必然力により命中 70 以上の技を必中と扱うため、ドラゴンダイブ＞ドラゴンクロー、かみなり＞10万ボルト、ふぶき＞れいとうビーム等が原則。
   - 例外: はりきり特性下では命中値がさらに低下するため、代替として命中値の高い技を採用可能。

**とんぼがえり／ボルトチェンジの例外**: タイプ一致でなくとも、相手に負担をかけながら交代できる点で有用性を認められ、採用が容認される。

### 2.4 持ち物

ヤトリックで採用可能な持ち物は火力上昇系に限定される。

| 分類 | 代表例 |
|------|--------|
| 三種の神器 | こだわりハチマキ、こだわりメガネ、いのちのたま |
| 火力補助 | たつじんのおび、ちからのハチマキ、ものしりメガネ、各種タイププレート |
| 専用アイテム | ラティ兄妹のこころのしずく、アローラガラガラのふといホネ、オーガポンの各種めん 等 |

**ヤロテスタントで条件付き容認されるもの**:

- **ゴツゴツメット**: 直接攻撃を受けた際のダメージ還元をサイクル戦に組み込む戦術で容認（例: ヤャラドスへの採用）。
- **とつげきチョッキ**: 「チョッキ込みでしか役割を成立させられないヤケモン（チョッキヤケモン）」に限り一部派閥で容認。超火力ヤケモンへの採用はヤロテスタント内でも否定される傾向が強い。

**いかなる場合も採用不可**:

- オボンのみ — 発動条件がヤケモンの戦術と噛み合わない。
- しんかのきせき — 火力上昇をもたらさず、かつ条件を満たすポケモンが現環境に存在しない。
- きあいのタスキ — 受け出しができないアタッカー向け道具であり、論者の戦術と相反する。

### 2.5 テラスタル / ダイマックス / Z技 / メガシンカ

| 要素 | 採用可否 |
|------|---------|
| テラスタル | 可（フォーマットが許す範囲で）。テラバースト採用時は A/C の個体値調整が必要になる場合あり |
| ダイマックス | ダイマックス前提の技構成は両派不可（SV 以降は廃止のため実質的に問題外） |
| Z技・メガシンカ | フォーマットが許可する場合のみ、通常ヤケモンと同等の制約に従う |
| 二刀（同一個体で A/C 両極振り） | 耐久が削られ過ぎるため両派不採用 |

## 3. 派閥定義

### 3.1 ヤトリック（原理主義派）

- 役割論理の禁則事項を例外なく遵守する論者。
- §2 の全規則を完全遵守。
- 環境因子への対応は「遭遇を避ける」「相性のよい別ヤケモンで受け直す」で処理し、ルールを曲げない。

### 3.2 ヤロテスタント（改革派）

- §2 の hard rules は遵守する（性格 4 種、A/C 極振り、S 振り不可、先制技不可、補助技不可、一致技必須）。
- ただし環境因子への実利的対応として、以下の選択を例外的に許容する。

| 環境因子への対応 | 判定 |
|----------------|------|
| 連続技（タネマシンガン等） | 容認 |
| 音技 | 容認 |
| ねごと（催眠対策） | 容認 |
| 低威力拘束技（候補技が乏しいヤケモン、例: ヤーユイ） | 容認 |
| ゴツゴツメット | 容認 |
| とつげきチョッキ | チョッキヤケモンに限り容認（派内で意見分裂） |
| ヤケモン落第生相当のポケモン試用 | 容認 |
| S 調整（歴史的例: 第五世代の S135 ポイヒガッサ対策） | 歴史的例外 |

**「環境因子」の定義（本コーパスにおける整理）**:
構築や立ち回りの工夫では対応できない、異教徒側の特定の型や嵌め戦術。第五世代のポイヒガッサ型がしばしば代表例として挙げられる。単に「このヤーティでは勝てない相手がいる」というだけの理由で禁則を緩めるのは環境因子対応ではなく、信仰心の問題とみなされる。

### 3.3 論外

§2 の hard rules のいずれか 1 つでも違反するものは「論外」。ヤトリック／ヤロテスタントいずれの系譜にも属さず、役割論者の作法から外れた「異教徒」の領域に分類される。

## 4. ヤケモン採用可否基準

### 4.1 評価階層

- **一軍**: 環境全般に対して役割を持ち、総合性能が突出し、広く論者に認められたヤケモン。
- **二軍**: 総合性能で一軍に届かない、または目立つ弱点があるが補完性能や軸性能が高いヤケモン。
- **候補外**: 上記の水準を満たさないポケモン。

### 4.2 Champions 環境におけるヤケモン候補（概観）

ここでは方針のみ示す。レギュレーション別の厳密な候補リストは、本ファイルではなくユーザー側の実運用判断に委ねる。

- 通常ヤケモン候補: アーマーガア、アシレーヌ、カイリュー、ガオガエン、ギルガルド、サザンドラ、バンギラス、ヒスイヌメルゴン、マリルリ 他。
- メガヤケモン候補: メガギャラドス、メガハッサム、メガバンギラス、メガヘラクロス、メガリザードン X/Y 他。
- チョッキヤケモン候補: レギュレーションにより 0〜2 体程度（M-1 等チョッキ不可レギュでは存在しない）。

### 4.3 却下傾向のあるポケモン（代表例）

- ガブリアス — 耐性の弱点が重く、他の竜を差し置く根拠に乏しい。
- ドラパルト対策枠としてのオーロンゲ — 耐久不足かつ役割範囲が狭い。
- スピンロトム — 性能水準が不足。
- メガバクーダ — 話題性のみで役割論理の軸には不適。

新規候補提案には役割適性の精査が求められ、思いつきレベルでの採用は許容されない。

### 4.4 推奨・提案の視点（論者の語り口）

ヤケモン候補を列挙・提案する際、以下の区分は**異教徒的発想**として使わない。論者の論理ではなく、環境メタ的な組み方に堕しているためである。

**使ってはならない区分**:

- 「物理アタッカー軸」「特殊アタッカー軸」「物アタ／特アタ」等の A/C 系カテゴリ分類
- 「受け」「受け特化」「受け寄り」「耐久型」「耐久ポケモン」等、役割遂行から切り離された「受け」単独評価
- 「抜きエース」「スイーパー」「先発要員」「起点作り」等、素早さ・展開速度に依拠した役割名
- 「サポーター」「補助枠」等、補助技前提の役割名

**論者が用いる正しい区分・語り口**:

- **何に対して役割を持てるか**: 「{メタ上位} に役割を持てるヤケモン」「{特定タイプ} 全般に役割を持てるヤケモン」
- **耐性と範囲**: 「耐性と範囲を兼ね備えたヤケモン」「範囲が広く広域の役割を担えるヤケモン」
- **火力の絶対値**: 「ダメージレースを制する火力を備えたヤケモン」「超火力で打ち合いを制するヤケモン」
- **サイクル内の位置**: 「受け出し起点となるヤケモン」「相手を倒しきり次の受け出しを通すヤケモン」

A/C どちらに極振りかは**種族値が高い方で自動的に決まる**（両方高ければヤケクソ振りの両刀）。論者が「A タイプか C タイプか」という軸で選ぶのではなく、選ばれたヤケモンに種族値が指示する形で決定される。

**受け概念の扱い**: 役割論理における「受け出し」はサイクルを回すための手段であり、補助技や定数ダメージ戦術に依存した純粋な「受け特化」構成は §2 に従って論外である。ガオガエンのようにいかくで物理を受け止める個体も、最終的には自身の A 火力で役割遂行を完遂する**攻撃役**として扱う（純粋な受けポケモンではない）。

**提案フォーマットの注意**: 「〜軸で候補を挙げる」形で列挙する際は、「物理軸／特殊軸」ではなく「耐性軸」「対 {タイプ} 軸」「対 {具体ヤケモン} 軸」など**役割ベースの軸**を用いる。候補表を出すときも「A 種族値」単体の比較ではなく、そのヤケモンが誰に対して役割を持つかを主要な観点とする。

## 5. 用語集

### 5.1 論者に関する用語

| 用語 | 意味 |
|------|------|
| 論者 | 役割論者の略称。冷静・紳士的で笑顔を絶やさない。 |
| 異教徒 | 役割論者でない者の総称。 |
| 迷える子羊達 | 異教徒の敬称（揶揄）。啓蒙・導きの対象とされる。 |
| ムック | 役割論者のふりをしつつ、場にそぐわないロジカル語法を使う異教徒。 |
| ガチャピン | ヤーティを使用していながらロジカル語法を用いない者。 |
| ヤーティ神 | 役割論理の守護神格。論者に必然力を授ける存在。 |

### 5.2 戦術・仕様に関する用語

| 用語 | 意味 |
|------|------|
| 必然力 | 高命中技を外さない、一撃必殺をかわす等、高確率事象を論者が必然的に引き起こす力。 |
| 運命力 | 一撃必殺を通す、急所を当てる等、低確率事象を異教徒側が引き起こしてしまう力。 |
| サイクル | ポケモンを交代しながら役割を回す試合展開。 |
| 打ち合い | 交代なしで技を撃ち合う局面。 |
| 三種の神器 | こだわりハチマキ／こだわりメガネ／いのちのたま。 |
| 言い訳振り | HBD に振り切った余剰 4 EV を S に回す従来仕様の配分。 |
| ゴミ | 役割を持てないポケモンを指す語。個体そのものへの軽侮ではなく「役割不在」のことを言う。 |
| ボケモン | 役割を持てないポケモン。 |
| ヤケモン | 役割を持てるポケモン。 |
| ヤーティ | 役割論理パーティの略。 |

### 5.3 ヤケモン／ボケモンの命名法則（概略）

- ヤケモンは先頭の音を「ヤ」に置換する（例: ボーマンダ → ヤーマンダ）。
- ボケモンは先頭の音を「ボ」に置換する（例: ガブリアス → ボブリアス）。
- 特例: 先頭音と同じ音が名前内に連続する場合や回文名のポケモンでは、複数箇所を置換するケースがある（例: ポッポ → ボッボ、ツボツボ → ボボボボ）。
- 詳細は `logical_grammar.md` §ヤケモン命名法則 を参照。
